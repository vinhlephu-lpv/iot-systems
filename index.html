Trạng thái hoạt động & Cảnh báo

Hệ thống giám sát và phản hồi thời gian thực với 3 trạng thái hoạt động rõ ràng, điều khiển trực tiếp đèn LED và còi báo:

BÌNH THƯỜNG - ĐÈN XANH

Cửa đóng kín (ĐANG ĐÓNG) VÀ Nhiệt độ trong khoảng an toàn (temp_min ≤ Nhiệt độ ≤ temp_max).

Ví dụ: Nhiệt độ 5°C, cửa đóng kín. Web hiển thị: Bình thường, LED Xanh sáng.
ĐANG MỞ CỬA - ĐÈN VÀNG

Cửa đang mở (> 0s), chưa vượt quá thời gian cài đặt, nhiệt độ còn an toàn. Hiển thị bộ đếm thời gian mở cửa.

Ví dụ: Cửa mở 5s (ngưỡng 10s). Web hiển thị: đang mở cửa < 10s, LED Vàng sáng.
CẦN XỬ LÝ - ĐÈN ĐỎ + CÒI

Cửa mở quá lâu (≥ thời gian cài đặt) HOẶC Nhiệt độ vượt ngưỡng an toàn (báo động tức thì).

Ví dụ: Cửa mở ≥ 10s → Web hiển thị: cần xử lý - cửa mở quá lâu; Nhiệt độ 33°C > 25°C → Web hiển thị: Nhiệt độ vượt ngưỡng 33.0 > 25.0°C. LED Đỏ sáng + Còi hú.

Hướng dẫn vận hành & Quy trình đồng bộ dữ liệu

Quy trình thiết lập cấu hình, truyền nhận dữ liệu hai chiều và kích hoạt cảnh báo tự động trên toàn hệ thống:

1
Thiết lập ngưỡng giám sát trên Web

Truy cập tab Cài đặt, điều chỉnh ngưỡng nhiệt độ (tối thiểu / tối đa) hoặc thời gian cho phép mở cửa, sau đó nhấn "Lưu cài đặt". Cấu hình mới lập tức được đồng bộ lên Firebase Realtime Database.

Ngay lập tức
2
ESP32 nạp cấu hình mới từ Firebase

Vi điều khiển ESP32 tự động lắng nghe và tải các thông số ngưỡng vừa cập nhật vào bộ nhớ giám sát thời gian thực.

~ 1-2 giây
3
Giám sát cảm biến & kích hoạt cảnh báo

Luồng phần cứng độc lập trên ESP32 quét liên tục với chu kỳ 20ms. Khi cửa mở quá thời gian quy định hoặc nhiệt độ vượt ngưỡng an toàn, hệ thống tự động kích hoạt Đèn Đỏ và Còi báo động tức thì.

Tức thì (20ms)
4
Hiển thị trực quan & lưu trữ lịch sử

Dữ liệu cảm biến thời gian thực, thời gian mở cửa, trạng thái thiết bị và các sự kiện cảnh báo được hiển thị đầy đủ trên Dashboard, đồng thời lưu vào lịch sử hệ thống.

Các đoạn mã nguồn cốt lõi trong Firmware (ESP32)

Mã nguồn được tối ưu hóa kiến trúc đa nhiệm thời gian thực trên vi điều khiển ESP32:

1. Khởi tạo tác vụ phần cứng độc lập (FreeRTOS Dual-Core Task) C++ / FreeRTOS 
// Khoi tao tac vu phan cung rieng biet tren Core 1 voi do uu tien cao
xTaskCreatePinnedToCore(
    hardwareAlarmTask,   // Ham thuc thi tac vu
    "HwAlarmTask",       // Ten dinh danh tac vu
    4096,                // Dung luong Stack (bytes)
    NULL,                // Tham so truyen vao
    2,                   // Muc uu tien cao (Priority 2)
    &alarmTaskHandle,    // Con tro quan ly tac vu
    1                    // Co dinh chay tren Core 1 (Core 0 danh cho WiFi/TCP)
);
2. Máy trạng thái giám sát chu kỳ 20ms và kích hoạt cảnh báo tức thì C++ / State Machine 
// Kiem tra phan cung dinh ky 20ms, phan hoi ngay lap tuc khong tre mang
void hardwareAlarmTask(void* pvParameters) {
    for (;;) {
        portENTER_CRITICAL(&stateMutex);

        // Doc trang thai cam bien tu MC-38 va tinh toan thoi gian mo
        bool doorNow = (digitalRead(PIN_DOOR_MC38) == (IS_MC38_NC ? HIGH : LOW));
        if (doorNow) {
            if (!isDoorOpen) doorOpenStartTime = millis();
            doorOpenDurationSec = (millis() - doorOpenStartTime) / 1000;
        } else {
            doorOpenDurationSec = 0;
        }
        isDoorOpen = doorNow;

        // Danh gia vi pham nguong va xac dinh cap do canh bao
        bool isTempAlert  = dhtReady && (currentTemp < TEMP_MIN || currentTemp > TEMP_MAX);
        bool isDoorTooLong = isDoorOpen && (doorOpenDurationSec >= DOOR_DELAY_SEC);

        int targetLevel = (isTempAlert || isDoorTooLong) ? 2 : (isDoorOpen ? 1 : 0);
        updateOutputs(targetLevel); // Cap nhat LED va Coi truc tiep qua GPIO

        portEXIT_CRITICAL(&stateMutex);
        vTaskDelay(pdMS_TO_TICKS(20)); // Chu ky quet 20ms
    }
}
3. Đồng bộ ngưỡng động hai chiều từ Firebase REST API C++ / HTTPClient 
// Nhan va cap nhat nguong moi tu Firebase Realtime Database
void fetchThresholds() {
    HTTPClient http;
    http.begin(buildFirebaseUrl(FB_PATH_THRESHOLDS));
    int httpCode = http.GET();
    if (httpCode == HTTP_CODE_OK) {
        String payload = http.getString();
        float tmin, tmax, dsec;
        if (parseJsonFloat(payload, "temp_min", tmin)) TEMP_MIN = tmin;
        if (parseJsonFloat(payload, "temp_max", tmax)) TEMP_MAX = tmax;
        if (parseJsonFloat(payload, "door_delay_sec", dsec)) DOOR_DELAY_SEC = (unsigned long)dsec;
    }
    http.end();
}
